# Praisey & Jabez – Wedding Invitation (React + Tailwind + Vite)

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist (upload this folder to Netlify/Vercel/GitHub Pages)
```

All names, date, venue and map link live in `src/config.js`.
The couple photo used by the puzzle is `src/assets/couple.jpg`.
